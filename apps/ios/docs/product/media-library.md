# Media Library

The current Media Library is a lightweight Product Experience for images a learner has
associated with words. It is reached through **You → Media Library**.

## Current behavior

- Opening a recognized word from Image Search associates that image with the word.
- A learner can also take or choose a photo directly from a word detail.
- The same image is stored once and can be associated with more than one word.
- A word can have more than one associated image.
- The library lists retained images with their associated words and saved date.
- A learner can open an image to see it at useful size and review its associated words.
- Removing an image from one word preserves it when another word still uses it.
- Deleting an image from the Media Library removes the image and all of its word associations.

Encounter Media is stored locally in the app's Application Support directory and participates
in normal system-managed device backup. The current Media Library does not provide account
sync or publishing.

## Not currently implemented

The Media Library does not currently import or analyze larger works such as books, PDFs,
subtitles, audio, or video. It has no Media Analysis results, Collections, or Read, Watch, and
Listen experiences. Those remain ideas rather than current app behavior.
