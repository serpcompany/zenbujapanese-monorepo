# Zenbu Japanese App

The native Zenbu Japanese app for iPhone, iPad, and Mac, from one target (ADR 0015).

Open [`ZenbuJapanese.xcodeproj`](ZenbuJapanese.xcodeproj/) in Xcode to build and run the app.

See [`docs/product/index.md`](docs/product/index.md) for the app's current user-facing behavior.
