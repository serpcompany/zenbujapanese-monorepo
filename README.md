# README

This project is for the main `zenbujapanese.com` website monorepo.

The `zenbujapanese.com` website idea/goals/plan is to generate organic (SEO) traffic with the intention of driving leads/users/sales of various PRODUCTS (apps, extensions, SAAS, tools, etc.) for learning/consuming japanese (for english speakers/learners) and/or english (for japanese speakers/learners).

The initial working 'idea/philosphy' is to offer these tools, apps, etc. for free (freemium model) with premium upgrades, namely being the ability to create a user profile and save your data, progress, bookmarks, etc. 

## Product Ideas

**Some of the product ideas include things like:**

- A jp/en dictionary app
  - ref: Nihongo Pro iOS app
- JP frequency word lists
  - ex: top 1000 most common words with accompanying "short conversations", "stories", "simple manga episodes", etc. created from the word lists for maximizing new learner understanding, drilling, retention, and ability to understand a large portion of everyday japanese quickly
  - ref: 
    - japanesevocabularyshort.com
    - devin's "1000 words/20 short stories" book
    - devin's "learn japanese through simple manga" book
- A host of other products semi mapped and documented already in `~/dev/repos/github@zenbujapanese/LEGACY/*`
