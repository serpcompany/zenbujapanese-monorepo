- **Browser extension, A.** Before merge, the code that needs no browser is tested, both builds
  and both packages must pass, and the browser tests load the test build in Chromium: the pages,
  the offscreen document's return, the content script on a real page, and a release download,
  offline. The `verify-extension` skill shows the same in branded Chrome with proof. Main gap,
  both tracked in [`tech-debt.md`](tech-debt.md) (Browser extension): the test surface's menu and
  dialog are driven by hand (#1062), and branded Chrome, where Chrome's own Translator runs, runs
  only on an agent's Mac, not in CI (#1063). The YouTube content script has run only in happy-dom:
  never on a stand-in watch page under YouTube's host, nor on YouTube.
- **Word Detail, B.** Every behavior in its product doc has an interaction test before merge, on
  the fixtures, and the side panel draws them. Main gap: nothing in the extension opens them yet,
  so no browser test or check by hand covers them until #957's Open Full Entry and #956's data
  arrive.
