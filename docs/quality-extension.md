- **Browser extension, B.** The code that needs no browser is tested before merge, and both builds
  and both packages must pass, but nothing loads the built extension in Chrome before merge: the pages, the ping,
  the offscreen document's return, the shadow root on a real page, the side panel opening
  from a click and fitting 320 px, and the header's site switch on a real tab are checked by hand. Main
  gap: no check that loads the unpacked build in Chrome runs before merge; #952 brings the agent
  Chrome harness into the repository.
