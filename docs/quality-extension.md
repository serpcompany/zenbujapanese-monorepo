- **Browser extension, A.** Before merge, the code that needs no browser is tested, both builds
  and both packages must pass, and the browser tests load the test build in Chromium: the pages,
  the offscreen document's return, the content script on a real page, and a release download,
  offline. The `verify-extension` skill shows the same in branded Chrome with proof. Main gap,
  both tracked in [`tech-debt.md`](tech-debt.md) (Browser extension): the test surface's menu and
  dialog are driven by hand (#1062), and branded Chrome runs only on an agent's Mac, not in CI
  (#1063). No browser test yet runs sqlite-wasm on `opfs-sahpool`, the extension's own download,
  or the conformance suites on WebAssembly (#956).
