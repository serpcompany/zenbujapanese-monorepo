- **Account and sync, C.** The client, every entity it syncs, and Apple's and Google's sign-in with
  only their sheets stood in, are tested against a stub server, and UI tests drive the sign-in sheet,
  a signed-in Profile, and what another device kept arriving. Main gap: no CI, and a real Apple or Google sign-in only on a device.
- **Subscription, C.** The client is tested against a stub server and a stand-in store, the
  StoreKit adapter against StoreKit with a configuration file, and UI tests buy, show each state,
  manage, and delete, and the accessibility audits walk the paywall, six states, and deleting with
  an App Store subscription. Main gaps: no CI, StoreKit's own purchase sheet only by hand, and no
  sandbox purchase.
- **Account tab and Profile, C.** The profile's rules, Reading Aids' preferences, an unreadable
  profile or Media Library index, and when a deleted photo's image goes are tested, and UI tests
  drive every row, the profile, and saving and deleting a Media Library photo. Main gap: CI runs
  only the check that every Swift package has a license text.
