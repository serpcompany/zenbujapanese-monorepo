# Zenbu brand assets

This directory contains the extracted Zenbu icon pack supplied on 2026-08-14. Devin Schumacher created the original `全` artwork and approved unrestricted commercial use by SERP and Zenbu.

`master/` and `vector/` contain reusable source exports. The platform folders contain prepared outputs for their named destinations. Delivery surfaces should copy only the assets they actually consume into their own runtime asset directories; these shared files are not bundled automatically.

The active iOS app icon is `apps/ios/App/Assets.xcassets/AppIcon.appiconset/AppIcon.png`, which matches `ios/AppIcon.appiconset/icon-1024.png` byte-for-byte.
