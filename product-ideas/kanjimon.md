# KanjiMon

A Gamified pokemon-esque style mobile app where users take pictures of Kanji as they encounter them in the real world. 

This behavior is akin to 'catching pokemon', where the Kanji have numbers (commonality, etc.) and also context (was it alone? in a proper name? as part of a word? etc.)

The user takes a picture of a kanji they see, and the app records certain attributes like: 
- date, location, context, etc.

(maybe) The user 'catches' the kanji by doing some learning/drills on it... easier kanji = easier to catch.

This can expand into a more gamified UI/UX, stats, etc. as the user catches (and learns) more kanji over their lifetime, learning different pronunciations / meanings based on its context (was it alone? in a proper name? as part of a word? etc.), etc.

This might help me catching rare ones more interesting or valuable.

Once any user "catches' (captures aka takes a picture of) a kanji in real life, that item is logged in our central database with its geo coordinates, and when any other user travels near it the kanji could "appear/attack" like it would if you were playing pokemon and walked past a wild pokemon... the user would then be able to 'battle it' (aka be quizzed on what it is or how to pronounce it or something) to give an opportunity to catch it.... this would make all users help build a VR/AR type IRL map of 'wild kanjis'
